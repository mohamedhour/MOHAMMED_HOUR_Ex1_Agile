- Filière : Développement Digital
- Groupe : 205

1- Projet  :
Un projet est un travail réalisé pour atteindre un objectif précis dans une période donnée.

2-Partie prenante  :
Une partie prenante est une personne ou une organisation qui participe au projet ou qui est concernée par le projet.

3-Contrainte d’un projet  :
Une contrainte est une chose qui peut limiter ou influencer la réalisation d’un projet, comme le temps, le budget ou les ressources.
